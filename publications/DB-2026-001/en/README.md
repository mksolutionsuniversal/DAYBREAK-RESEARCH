## ClickFix on macOS: data collection begins before the password is entered

Static analysis, dynamic analysis and digital forensics of a multi-stage infostealer.

**Research codename:** DAYBREAK BLUE  
**Author:** Michal Kurzdym  
**Publisher:** MK Universal Solutions Ltd  
**Research period:** 18–21 November 2026; comparison with the incident on 9 November  
**English edition:** 1.0.0 · repository package v1.1.0  
**Documentation licence:** [CC BY 4.0](../../../LICENSE)

[Technical report](report.md) · [Evidence matrix](evidence.md) · [References](references.md) · [Defensive indicators](indicators.md) · [Figures](figures/README.md)

Key finding: local collection and archiving preceded successful password validation. Communication attempts were recorded in the isolated laboratory, but delivery to an external recipient was not confirmed. The operator and specific malware family were not established.

This is a British English translation of the same research publication, not a new investigation. The [original Polish release v1.0.0](https://github.com/mksolutionsuniversal/DAYBREAK-RESEARCH/releases/tag/v1.0.0) remains unchanged. The original evidence remains in a separate secured archive.
