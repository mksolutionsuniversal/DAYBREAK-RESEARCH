# Wskaźniki defensywne DB-2026-001

[CSV](IOC.csv) · [JSON](IOC.json) · [Raport](../pl/report.md)

Zestaw 17 wskaźników obejmuje 4 skróty SHA-256, 12 domen i 1 adres IPv4. Domeny i adres IP są defangowane. Podział campaign/historical odróżnia badanie 18–21 listopada od incydentu 8–9 listopada 2026.

`research_window` oznacza udokumentowany okres badawczy, nie ustaloną datę pierwszej i ostatniej aktywności infrastruktury. `confidence` odnosi się do opisanej roli i podstawy obserwacji, nie do atrybucji osoby lub rodziny malware. Wskaźniki statyczne nie oznaczają potwierdzonego połączenia; obserwowane próby nie oznaczają odebrania danych. Nie sprawdzano aktualnej dostępności złośliwej infrastruktury ani nie nawiązywano z nią połączeń podczas redakcji. Nie należy automatycznie traktować wszystkich wartości jako aktualnej listy blokowania.

CSV i JSON zawierają te same rekordy. Wartości pochodzą z raportu i matrycy dowodowej, nie z ponownego pobrania próbek.
